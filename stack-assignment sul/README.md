# Stack Assignment

Implementasi Stack (linked list) dan tiga aplikasinya dalam Java.

| File | Fungsi |
| --- | --- |
| `Stack.java` | ADT Stack: `push`, `pop`, `top`, `isEmpty` |
| `ParenthesisChecker.java` | Mengecek kurung `()`, `[]`, `{}` seimbang atau tidak |
| `InfixToPostfix.java` | Mengubah ekspresi infix menjadi postfix |
| `PostfixEvaluator.java` | Menghitung hasil ekspresi postfix |
| `Main.java` | Program uji |

## Menjalankan

```
javac *.java
java Main
```
